# Repository Scope

## SKST

このリポジトリで扱う対象です。

- 埼玉鶴瀬道院
- 志木スポーツ少年団
- イベント写真館

主なコード:

- `wp-content/themes/doin`
- `wp-content/themes/jsc`
- `wp-content/themes/Saitama Tsuruse`

## SKKP

別リポジトリで扱う対象です。このリポジトリには含めません。

- 少林寺拳法大会システム
- `wp-content/plugins/sktp-core`
- `wp-content/themes/sktp`

## 作業ルール

- WordPress Core は編集対象外です。
- 一般配布プラグイン・一般配布テーマは編集対象外です。
- Local 環境で確認したうえで、必要な独自コードのみこのリポジトリへ反映します。
- 設計書・仕様書は `docs/` 配下へ置き、実装対象の根拠として扱います。
