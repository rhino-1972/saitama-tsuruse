# お問い合わせ送信完了ページ

Contact Form 7の `wpcf7mailsent` イベント（送信成功）で、固定ページ `contact/お問い合わせ完了` に移動します。入力エラー・迷惑メール判定・送信失敗では移動しません。

遷移先はWordPressの `get_permalink()` から取得するため、Localと本番でURLを固定する必要はありません。公開中の完了ページがない場合はリダイレクト処理を読み込みません。

完了ページの本文は、管理画面の固定ページ「お問い合わせ完了」で編集できます。設定時点では本文は空です。ページのサイドバーにサブページ一覧は表示しません。

表示と送信成功イベントによる遷移をブラウザで検証しています。実際のメール送信は行っていません。
