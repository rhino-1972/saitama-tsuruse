# テーマ導入時の必要プラグイン

埼玉鶴瀬道院の `doin` テーマを有効化すると、必要プラグインが不足・未有効化の場合、管理画面「外観 ＞ 必要プラグイン」へ案内します。ZIPをアップロードしただけではテーマのPHPは動かないため、有効化時に確認します。

対象はEvent Organiser、NextGEN Gallery、Contact Form 7、Really Simple CAPTCHAです。旧The Events Calendarや、別リポジトリのSKKPは対象外です。

1. 未インストールの行の「インストール」を押すと、WordPress標準インストーラーが公式配布元から取得します。
2. インストール済みの行の「このサイトで有効化」を押します。
3. すべて「有効」になったことを確認します。

マルチサイトではインストールはネットワーク管理者のみ可能です。有効化はサイト単位で行い、自動でネットワーク全体を有効化しません。すでに有効なプラグインの再インストールや更新はしません。

権限・nonce検証、PHP互換性、ネットワークエラー、書き込み権限、ファイル転送認証はWordPress標準のインストール・有効化処理が扱います。許可なく公開アクセス中にインストールする処理はありません。

テーマの有効化を伴わない更新でも、不足があれば管理画面に案内を表示します。「外観 ＞ 必要プラグイン」からいつでも状態を確認できます。

親テーマLightning、mu-plugins、固定ページ本文、フォーム、ギャラリー、イベントの設定は別途導入・復元してください。この機能はプラグイン本体の導入を案内するものです。
