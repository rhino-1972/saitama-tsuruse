# Slide 2
目的
【
現状
】
１、埼玉県連で作成されたサイトは、メンテナンスが難解であり、修正箇所により有料化している
２、今後、志木スポーツ少年団を追加する場合、有料となる
３、皆さんより提供された写真や動画をサイトに共有するのが困難である
【
提案
】
１、複数のサイトを統合し管理しやすくメンテしやすいようにする
２、それぞれのサイトに必要な情報と共有する情報を融合化し同じ情報を複数箇所で登録しない様にする
