# 見学・入門案内の編集

「固定ページ ＞ 見学・入門案内」から編集する。入門・体験案内・電話番号・練習日時・Q&Aはすべて通常のWordPressブロック。テーマ内のひな形は新規作成時にだけ使われ、既存固定ページの文章を自動上書きしない。

見出しはH3。「入門」「体験・見学」「よくある質問 Q＆A」の3区分。入門と体験は左側イラスト・右側本文、その下に枠付き連絡先・修練時間を配置する。

## Q&A追加

- 挿入ボタン「＋」の「パターン ＞ 埼玉鶴瀬道院 ＞ 質問と先生の回答」を挿入し、質問・回答の文章を編集する。
- またはリスト表示から質問と回答を含む外側のグループを選び、「複製」する。
- 各Q&Aの外側グループは `doin-qa-pair`、質問は `doin-qa-question`、回答は `doin-qa-answer` のCSSクラスを持つ。複製するとアイコン・吹き出しも維持される。

最初の4組は添付の質問・回答を使用。日程欄は添付に記載された水曜・土曜の日時を採用しているため、現在の修練日時に変更する場合も固定ページで編集する。

## 変更ファイル

- `wordpress/themes/doin/functions.php`: 修練日程のH3化・カレンダーと年間行事の並べ替え、案内ひな形・Q&Aパターン登録。
- `wordpress/themes/doin/page-content/trial-entry.html`: 通常ブロックのひな形。
- `wordpress/themes/doin/trial-entry.css`: 案内欄・吹き出し、各ページ見出しとお問い合わせ送信ボタンの共通スタイル。トップのお知らせも赤・グレーの共通見出しラインを使用する。
- `wordpress/themes/doin/assets/images/trial`: 入門・体験イラスト、Q&A用アイコン。
- `docs/page-content/doin-trial-entry.html`: Localに保存した固定ページ本文。
- `docs/page-content/trial-entry-before-blocks.html`: 今回の更新前の本文。

## 画像

入門・体験イラストは既存サイトの参照画像を使用。Q&Aアイコンは内蔵ImageGenで新規生成した透明背景の画像。生成指示: 「左に緑の普段着で質問する一般の成人、右に黒い道着を着て優しく笑う白髪の先生。日本の地域サイトに合うイラスト、同じ大きさの正面バストアップ、文字なし、透明背景」。左右をCSSで分けて表示する。
